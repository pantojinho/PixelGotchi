Crie o seu bichinho

Comece de um dos seis bichinhos, desenhe cada pose na grade 8×8 de verdade, teste no simulador e envie para a sua placa pelo cabo USB. Tudo fica salvo neste navegador; baixe o arquivo do projeto para guardar. Guia do editor.

Projeto

Arquivo

O .art é o formato de texto do repositório, para quem quiser incluir o bichinho no código.

Clique ou arraste para pintar; botão direito apaga. Preto é LED apagado: a silhueta é feita de cor, não de contorno. O bichinho fica apoiado na última linha.

Animações

Prévia com a aparência dos LEDs.

Conferência

    Enviar para a placa

    Chrome ou Edge no computador, com a placa num cabo USB-C de dados. A placa precisa do firmware atual: se ela não responder, atualize antes pelo instalador.

    Sem trocar, ele aparece como 7ª espécie na seleção. Se o seu bichinho atual já for o do editor, o desenho novo aparece na hora.
