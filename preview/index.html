Experimente BOOT + gestos

Clique no BOOT para alimentar. Segure 0,6 s e solte para abrir o menu; clique ou incline para trocar o ícone; segure e solte para confirmar.

Maquete interativa dos cuidados, sem simular o relógio, DNA ou persistência do firmware. Na placa, o menu mostra apenas o ícone e os pontos. Espaço = BOOT; setas = inclinar. Reset: segure por 8 s (barra vermelha a partir de 3 s).
